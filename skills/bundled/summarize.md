---
name: Summarize
description: Summarize content from files, web pages, or text
when-to-use: When the user asks to summarize something
allowed-tools: [read_file, web_fetch]
arguments: target
argument-hint: File path, URL, or text to summarize
user-invocable: true
version: 1.0
---

Read the provided content and create a concise summary. Focus on:
1. Main points and key takeaways
2. Important details and data points
3. Conclusions or recommendations

Keep the summary organized and easy to scan. Use bullet points for multiple items.
